# DTGallery

Welcome to **DTGallery**, a sleek and modern platform designed to showcase your photography portfolio. Whether you're a professional photographer or an enthusiastic hobbyist, DTGallery provides a visually stunning and user-friendly space to display your work beautifully.

## Features
- **Portfolio Display**: Organize and showcase your photographs with categories like Landscape, Portrait, and others for better viewer navigation.
- **Interactive Galleries**: Users can click on images for enlarged views and smoothly navigate through different photos.
- **Responsive Layout**: Designed to look great on all devices, from desktop computers to mobile phones, with an adaptable grid layout.
- **Modern and Minimal Design**: Clean interface that emphasizes your photographs, making them the focal point.
- **Image Categorization**: Create different galleries for easy access to various photography styles, from candid moments to stunning landscapes.
- **About Me Section**: Personalize your gallery by sharing your story with visitors, making it a full experience beyond just images.

## Installation

To run DTGallery locally:
- 1.**Clone the repository**:

   ```git clone https://github.com/dharan-sdc/DTGallery.git```
   
- 2.**Navigate into the project folder**:

   ```cd DTGallery```
   
- 3.**Open the index.html file in your preferred web browser to see the site in action.**

   -If you want to preview it live on a local server, consider using tools like Live Server.

- 4.**Customization:**

  - Change the images in the img/ folder with your own photos.
  - Update the content in the portfolio.html and index.html files to match your personal information and portfolio.

## Technologies Used

- **HTML5**: Semantic structure and markup for the website.
- **CSS3**: Styling and design for a modern, responsive layout.
- **JavaScript**: Adds interactivity, such as image enlargement and smooth transitions.
- **SCSS**: Used for styling to create nested stylesheets and improve maintainability.
